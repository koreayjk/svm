# 리허설 체크리스트 (실제 폰 · 실제 Supabase)

자동 테스트가 못 보는 것을 **사람 몇 명이 실제로 한 번씩** 해 보는 날입니다. 행사(11/20) 최소 1주 전에, 30~40분이면 됩니다.

## 준비 (10분)
- 사람: 관리자 1 · 나라 리더 1 · 선교사님 1(아무나 대신) · 학생 2 → 최소 4~5명, 각자 **자기 폰**
- 이메일 5개 (예: 가족·지인 이메일, `이름+svm1@gmail.com` 처럼 `+` 별칭도 가능)
- 관리자 계정은 이미 있어야 하고, 나머지는 앱에서 새로 가입합니다.
- 리허설 후 이 계정들은 앱의 **마이 → 계정 삭제**로 지웁니다.

## A. 가입과 첫 화면 (학생 2명)
- [ ] 앱 주소(또는 설치한 앱)를 열어 가입 → 확인 메일이 오는가 → 링크를 누르면 들어가지는가
- [ ] 영어/한국어를 바꾸면 화면이 바뀌는가 · 홈에 오늘 모임 카드가 보이는가
- [ ] 나라 하나에서 **이름 쓰기** → 숫자가 올라가는가
- [ ] 같은 나라를 품은 두 학생이 **기도 짝 찾기**로 이어지는가 · 서로 글이 보이는가

## B. 신청 → 승인 (학생 1 + 관리자 + 나라 리더)
- [ ] 학생이 신청서를 낸다 → 관리자에게 알림이 오는가
- [ ] 관리자가 **마이 → 나라 리더 지정**(관리 → 회원)으로 리더를 지정한다 · 리더에게 해당 나라 신청이 보이는가
- [ ] 리더가 승인한다 → 학생 홈에 **출발 D-day 카드**가 뜨는가
- [ ] 학생이 **여정 일정표**에 항공편을 적고 **가족과 공유**를 눌러 본다 (공유 창/복사)
- [ ] 보험 증서 사진 업로드가 되는가 (실제 폰 사진)

## C. 선교 중 안전 (학생 + 나라 리더 + 관리자) ← 가장 중요
- [ ] 관리자가 신청 상태를 **선교 중**으로 바꾼다
- [ ] 학생 홈에 **도움이 필요하세요?** 카드가 보이는가
- [ ] 학생이 **안전해요 체크인**을 누르면 리더 화면에 보이는가
- [ ] 학생이 **비상 버튼**(두 번 누르기)을 누른다 → 리더와 관리자에게 알림이 오는가 (푸시를 켰다면 폰이 울리는가)
- [ ] 리더가 **확인했어요**를 누르면 학생 화면이 "리더가 확인했어요"로 바뀌는가
- [ ] "내 위치 포함"을 체크하고 보내면 위치 권한 창이 한 번 뜨고, 지도 링크가 전달되는가
- [ ] 학생이 **이제 안전해요**를 누르면 정리되는가

## D. 채팅 · 소식 (전원)
- [ ] 채팅 메뉴에서 나라 방에 들어가 서로 메시지가 실시간으로 오는가 · 참여자 목록이 맞는가
- [ ] 리더 방(전체/나라별)은 리더·선교사님·관리자에게만 보이고, 학생에게는 **안 보이는가**
- [ ] 나라 리더가 자기 나라에 사진·유튜브 영상·소식을 올린다 → 학생 화면에 나오는가
- [ ] 다른 나라에서는 올리기 버튼이 **안 보이는가**
- [ ] 개선 제안에 글+사진+댓글을 달아 본다

## E. 컨퍼런스 (관리자 + 학생)
- [ ] 홈페이지 `conference/` 에서 개인 등록, 단체 등록(단체 이름·인원)을 해 본다
- [ ] 관리자 앱 **마이 → 컨퍼런스 접수**에 등록자가 보이는가 · 체크인 · 현장 등록 · 숫자
- [ ] 당일 화면 미리보기: 앱 주소 끝에 `?demo&confday` (데모 모드)로 "오늘 밤" 카드 확인
- [ ] 행사 이벤트 설명(관리 → 이벤트)에 **당일 순서**를 줄마다 적어 두었는가

## F. 푸시 알림 (설정을 마쳤다면)
- [ ] 아이폰·안드로이드 각 1대에서 알림 허용 → 다른 계정이 메시지/승인으로 알림을 만들면 폰에 푸시가 오는가
- [ ] 알림을 누르면 해당 화면이 열리는가
- [ ] Supabase **Edge Functions → push → Logs** 에 `["sent"]` 가 보이는가

## G. 끝나고
- [ ] 막힌 곳·헷갈린 문구를 적어 두기 (개선 제안 게시판에 올려도 됩니다)
- [ ] 리허설 계정 지우기 (마이 → 계정 삭제)
- [ ] 심각한 문제가 있었다면 그 화면 캡처와 시간을 알려 주세요
